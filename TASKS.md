## 🔴 Уровень 8 — Физика агентов (IDM / MOBIL)
> **Цель:** агенты двигаются физически корректно, не телепортируются и не проезжают друг сквозь друга.

- [ ] **IDM — Intelligent Driver Model** *(Jules)*
  - Формула ускорения: `a = a_max · [1 − (v/v0)^δ − (s*/s)^2]`
  - Параметры на агента: `v0` (желаемая скорость), `T` (headway), `a`, `b`, `s0`
  - API: `/api/physics` отдаёт позиции агентов по IDM на каждый тик
- [ ] **MOBIL — модель перестроений** *(Jules)*
  - Критерий смены полосы: выгода для себя и безопасность для заднего соседа
  - Параметры: `p` (politeness), `a_thr`, `b_safe`
- [ ] **Shock waves — обратные волны заторов** *(Jules + Codex)*
  - Пробка «едет назад» как волна уплотнения
  - Визуализация волны цветом на дороге (Codex)
- [ ] **Реалистичная модель перекрёстков** *(Jules)*
  - Gap acceptance: агент проезжает если зазор > `T_accept`
  - Конфликтные точки, приоритеты по типу дороги
- [ ] **Стохастические параметры агентов** *(Jules)*
  - Каждый водитель имеет свой `reaction_time`, `desired_speed`, `aggressiveness`
  - Распределение: нормальное с заданными μ и σ

## 🟡 Уровень 10 — Аналитика и метрики для ресёрча
> **Цель:** набор метрик, достаточный для публикации в traffic engineering журнале.

- [ ] **MFD — Macroscopic Fundamental Diagram** *(Jules + Codex)*
  - График: поток (veh/h) vs плотность (veh/km) по всей сети
  - Отдельный endpoint: `/api/analytics/mfd`
  - Визуализация: интерактивный scatter plot (Codex)
- [ ] **Travel Time Reliability (TTR)** *(Jules)*
  - Buffer Index = (PTI − TTI) / TTI
  - Planning Time Index (95-й перцентиль / free-flow time)
  - Добавить в `/api/analytics` response
- [ ] **Emissions model COPERT-lite** *(Jules)*
  - CO₂ и NOx по скоростному профилю каждого агента
  - Endpoint: `/api/analytics/emissions`
  - На карте: тепловой слой выбросов (Codex)
- [ ] **Network Resilience Score** *(Jules)*
  - Betweenness centrality для рёбер графа
  - Скор деградации при удалении топ-N рёбер
  - Endpoint: `/api/analytics/resilience`
- [ ] **Monte Carlo прогоны с доверительными интервалами** *(Jules)*
  - N = 30–100 прогонов с разным random seed
  - Возвращает: mean ± CI для каждой метрики
  - Endpoint: `/api/analytics/montecarlo?runs=50`
- [ ] **Sensitivity analysis** *(Jules)*
  - Параметрический sweep: трафик ×1.0, ×1.1, ×1.2, ×1.5, ×2.0
  - Возвращает таблицу KPI по каждому уровню нагрузки
  - Endpoint: `/api/analytics/sensitivity?scale=1.2`
