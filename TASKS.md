# 🚦 PROJECT: Almaty Traffic Simulation Model
**Type:** Autonomous AI Development Project
**Core Framework:** Next.js
**Target Location:** Almaty, Kazakhstan

## 🤖 РАЗДЕЛЕНИЕ ЗОН ОТВЕТСТВЕННОСТИ (JULES & CODEX)

**Jules (Фоновый инженер / Бэкенд):**
- Твоя задача: Алгоритмы, математика, выгрузка данных, расчет маршрутов и генерация датасетов.
- Результат работы: Скрипты генерации данных и API-роуты в Next.js (например, `/api/trips`, `/api/analytics`), которые отдают готовый JSON. Ты НЕ трогаешь UI-компоненты.

**Codex (Фронтенд-инженер / UI):**
- Твоя задача: Визуализация, интерактивность, дашборды, элементы управления.
- Результат работы: React-компоненты (Mapbox, Deck.gl), которые запрашивают JSON у API-роутов и отрисовывают это на экране. Выстраивание плавных анимаций и UI-контроллеров.

**Контракт данных (Data Contract):**
Взаимодействие идет строго через согласованный JSON. Jules готовит данные, Codex пишет фронтенд, который эти данные читает.
