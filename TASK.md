# 🚦 PROJECT: Almaty Traffic Simulation Model
**Type:** Autonomous AI Development Project
**Core Framework:** Next.js
**Target Location:** Almaty, Kazakhstan

## 🤖 РАЗДЕЛЕНИЕ ЗОН ОТВЕТСТВЕННОСТИ (JULES & CODEX)

**Jules (Фоновый инженер / Бэкенд):**
- Твоя задача: Алгоритмы, математика, выгрузка данных из OSM, расчет маршрутов (A*).
- Результат работы: Скрипты генерации данных и API-роуты в Next.js (например, `/api/graph`), которые отдают готовый JSON. Ты НЕ трогаешь UI-компоненты.

**Codex (Фронтенд-инженер / UI):**
- Твоя задача: Визуализация, интерактивность, дашборды.
- Результат работы: React-компоненты (Mapbox, Deck.gl, Leaflet), которые запрашивают JSON у API-роутов (созданных Jules) и отрисовывают это на экране. Ты НЕ пишешь тяжелые алгоритмы маршрутизации.

**Контракт данных (Data Contract):**
Взаимодействие идет через JSON. Jules готовит данные (координаты узлов, веса ребер), Codex пишет фронтенд, который эти данные читает.

## 🗺️ ROADMAP & EXECUTION PHASES (Спринты)
Агенты должны выполнять работу строго в следующем порядке:

### 🟢 Уровень 1: Базовый (MVP) - *Current Focus*
- [ ] Карта города: Интерактивная карта с основными дорогами Алматы.
- [ ] Транспортный граф: Узлы (перекрёстки) + рёбра (дороги) с весами (скорость, длина).
- [ ] Генерация транспорта: Случайное или паттерное появление машин в разное время суток.
- [ ] Маршрутизация: Алгоритм A* или Dijkstra для поиска пути.

### 🟡 Уровень 2: Средний (Реалистичность)
- [ ] Светофорная система: Циклы светофоров на ключевых перекрёстках Алматы (пр. Аль-Фараби, пр. Абая).
- [ ] Часы пик: Утренний (8–9ч) и вечерний (18–19ч) трафик с реальной плотностью.
- [ ] Типы дорог: Проспекты, улицы, дворовые проезды с разными скоростными лимитами.
- [ ] События: Случайные ДТП и блокировки, меняющие потоки.
- [ ] Тепловая карта: Визуализация загруженности дорог в реальном времени.

### 🟠 Уровень 3: Высокий (Продвинутая модель)
- [ ] Реальные данные: Импорт дорожной сети из OSM.
- [ ] Агентная модель: Каждый автомобиль — отдельный агент с поведением (агрессивный, осторожный).
- [ ] Адаптивные светофоры: Смена фазы в зависимости от очереди машин.
- [ ] Общественный транспорт: Автобусы, выделенные полосы и их влияние на трафик.
- [ ] Сценарии: Закрытие дороги, дорожные работы, праздники.

### 🔴 Уровень 4: Финальный (Презентационный)
- [ ] Аналитика: Среднее время в пути, пробки, пропускная способность узлов.
- [ ] Dashboard: Индекс загруженности (0-100%), графики по времени суток.
- [ ] Экспорт отчётов: PDF/CSV с аналитикой.
- [ ] ML Прогноз: Предсказательная модель для прогноза загруженности на следующий час.
