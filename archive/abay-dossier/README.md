# Archive: Abay signal-retiming dossier

This folder keeps the documents and release tooling of the project’s previous iteration: an evidence-gated dossier for one fixed scenario (signal retiming on Abay Avenue, 36 s → 32 s), generated by a Python pipeline with JSON Schema contracts, SHA-256 hashes and an immutable release transaction.

The current project, [Almaty Traffic Lab](../../README.md), replaced that single-case web dossier with an open, in-browser model in which visitors choose the street and the change themselves. The ideas carried over: claim levels (real data vs. proxy), a run passport with hashes, and an explicit list of limitations.

What is still live in the repository:

- the Python package `src/traffic_sim/` (agent-based simulator, paired experiment, KPI and dossier generation) and its tests in `tests/`;
- `scripts/bootstrap_portfolio.py`, which regenerates the dossier evidence pack (`PYTHONPATH=src python scripts/bootstrap_portfolio.py`).

What is archived here and no longer part of the web app: the methods and validation write-ups, the release-candidate scripts, the Docker setup of the old dossier site, the Lighthouse and security-tool configuration, and the original design drafts.
