# v0.1.0 Repository Hygiene Inventory

`git ls-files -ci --exclude-standard` reports 39 legacy tracked-and-ignored paths in the current history. This report classifies them for the public release tree; it does not delete or untrack any existing user artifact.

| Class | Paths | Count | Release treatment | Reason |
|---|---|---:|---|---|
| Finder metadata | `.DS_Store`, `data/.DS_Store`, `src/.DS_Store` | 3 | Remove from index and working release tree | Machine-local metadata, never a source/evidence input |
| Python bytecode | `src/traffic_sim/__pycache__/*.cpython-312.pyc` | 7 | Remove from index and working release tree | Derived interpreter cache, incompatible with pinned Python 3.14 release lane |
| Legacy broad-source data | `data/analytics.json`, `data/analytics_report.csv`, `data/corridors/almaty_major_roads.json`, `data/scenarios/almaty_report_scenarios.json`, `data/scenarios/examples.json`, `data/time_profiles/almaty_weekday.json`, `data/trips.json`, `data/zones/almaty_od_matrix.json`, `data/zones/almaty_zones.json` | 9 | Remove from public release index; retain locally until owner confirms archival | Not in the narrowly allowlisted `portfolio.sources.json`; removing tracking does not delete a local copy |
| Historical generated reports | 18 UUID-named research HTML reports plus `reports/almaty-center.html` and `reports/demo.html` | 19 | Remove from public release index; retain locally or archive outside the repository | Generated output is intentionally ignored; canonical promoted evidence is regenerated from a clean candidate |

## Required owner action

The release candidate cannot meet REL-09 while these paths remain tracked and ignored. The owner must approve a non-destructive index cleanup that keeps any needed local files available, followed by a clean candidate bootstrap. History rewrite is not recommended or implied by this inventory.

## Verification after approval

```bash
git ls-files -ci --exclude-standard
git status --short
npm run verify:release -- --stage candidate
```

The first command must return no paths. The candidate verifier will then prove that the curated source allowlist and immutable generated release pack stand independently of the removed legacy files.
