# Figma Dashboard Screen Brief

Use this brief to create the planned Figma screens when a target Figma file is connected.

1. Main 3D Simulation Dashboard
   - Fullscreen 3D map canvas.
   - Right control panel with preset, time, policy, provider, scenario and playback controls.
   - Bottom status strip for active vehicles, average speed, road load and selected mode.

2. Scenario Editor
   - Selected road detail.
   - Incident type selector: accident, repair, closure, capacity reduction, signal delay, weather.
   - Strength and duration controls.

3. Time Control / Day Timeline
   - Manual time picker.
   - Auto-time toggle.
   - Day timeline with morning, lunch, evening peak and night bands.

4. Road Detail + Capacity Panel
   - Road class, lanes, speed, capacity, queue length and current load.
   - Editable capacity/speed fields.
   - Historical/synthetic observations table.

5. Statistics / Before-After Analysis
   - Baseline vs scenario metrics.
   - Hot roads ranking.
   - Corridor congestion chart.
   - Export buttons for JSON and CSV.
