# Baseline MVP Inventory

Created: 2026-06-05  
Goal: [[G001 - Baseline MVP Inventory]]

This inventory records the current MVP surface for the first sellable epic. It is intentionally conservative: a feature is only buyer-facing evidence when it has an implementation path, artifact, or verification signal.

## Status Labels

| Status | Meaning |
|---|---|
| `implemented` | Code/data/artifact exists and can be verified locally. |
| `partial` | Useful surface exists, but it is incomplete, cached, derived, or not wired end-to-end. |
| `stub` | Placeholder or fallback behavior exists but is not decision evidence. |
| `derived` | Value is generated from synthetic/proxy logic or transformed from local files. |

## Baseline Risks

- Existing analytics are stochastic/proxy-generated unless seeded or replaced by reproducible simulation outputs.
- Some dashboard labels mention "level" capabilities; buyer-facing dossier wording must use claim labels from [[Claim Ledger]] instead.
- Cached OSM/GeoJSON road data should be described as local imported road geometry, not live transport data.
- Existing research report export is useful evidence, but it is not the first sellable dossier because it lacks a run passport, executive KPI block, CAPEX/OPEX placeholders, limitations, and buyer recommendation.
